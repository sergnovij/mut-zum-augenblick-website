# Susanne Hartung – Photography Website Prototype

## Project Overview

This project is a responsive website prototype for **Susanne Hartung – Fotografie**, focusing on authentic portrait photography, particularly for people who feel uncomfortable or camera-shy in front of a camera.

The website is based on the philosophy:

**„Mut zum Augenblick.“**

Its central message is:

**„Authentische Porträts für kamerascheue Menschen.“**

The design aims to communicate trust, empathy, authenticity and professional photographic experience.

## Design Concept

The website uses a refined editorial design with:

- Warm ivory, beige and sepia colour palette
- Elegant serif typography
- Minimalist navigation
- Large photographic elements
- Generous white space
- Personal and approachable German-language content
- Responsive layouts for desktop and mobile devices

## Website Sections

The homepage includes the following sections:

1. **Hero Section**
   - Susanne Hartung's portrait
   - Main headline: „Mut zum Augenblick.“
   - Introduction to her portrait photography

2. **Portrait Gallery**
   - Selection of portrait photographs
   - Interactive image enlargement

3. **Camera-Shy Visitors**
   - Introduction addressing people who feel uncomfortable being photographed
   - Message: „Du bist nicht unfotogen.“

4. **Photography Philosophy**
   - Susanne's personal approach to portrait photography
   - Emphasis on empathy, patience and authentic expressions

5. **Photography Approach**
   - Explanation of how Susanne works with her clients
   - Building trust before taking photographs

6. **Client Story**
   - Example of the lawyer's portrait session
   - Demonstration of how a relaxed environment can help overcome camera anxiety

7. **How a Photo Session Works**
   - Four steps: Arriving, discussing expectations, feeling comfortable and taking authentic portraits

8. **About Susanne**
   - Professional background
   - Studies in Visual Communication at FH Dortmund
   - Experience in photojournalism and editorial photography
   - Professional career since 1998
   - Work in Berlin since 2008

9. **Contact**
   - Personal invitation to get in touch
   - Contact link placeholder

## How to Run the Website

No installation or additional software is required.

1. Download and extract the project ZIP file.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your default browser.

Recommended browsers:

- Google Chrome
- Mozilla Firefox
- Safari
- Microsoft Edge

## Images

The supplied portrait of Susanne Hartung is used in the hero and About sections.

The prototype is built using:
